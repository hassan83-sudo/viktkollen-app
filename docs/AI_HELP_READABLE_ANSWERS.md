# AI Help answer layout

The chat previously rendered each answer in a single paragraph. Plan answers
also joined quotas with semicolons, so existing whitespace styling could not
provide useful headings or list semantics.

Assistant answers now use a small text-only renderer: blank lines become
paragraphs, `#`–`####` heading lines become level-three headings below the
AI Help section title, and hyphen/star/bullet or numbered lines become lists.
Explicit single line breaks remain visible. Long unstructured prose is grouped
into paragraphs of at most three sentences using `Intl.Segmenter`; no sentence
or number is rewritten. Browsers without Segmenter keep the original paragraph.
Continued ordered lists retain their starting step number.

Every content item remains a React text child. HTML, images, Markdown links
and executable URLs are never interpreted. There is no HTML injection API,
Markdown dependency, external image loading, or added link execution.

Verified plan answers now have one heading per selected plan, individual quota
and unmetered-feature bullets, and a separate difference summary. Price labels
use localized wording, such as `9 kr/månad`, from the same numerical source.
Plan selection, prices, quotas, readers and authentication are unchanged.
The model prompt requests short paragraphs/list lines while preserving the
existing four-sentence instruction and token/cost controls.

CSS uses logical indentation, start alignment, bidirectional paragraph handling,
comfortable spacing and long-token wrapping. At 420px and below, the question
form uses one column so inputs and buttons fit narrow screens.

configuration was changed. This is intentionally not a full Markdown renderer;
tables, links, images and inline Markdown formatting stay literal text.
