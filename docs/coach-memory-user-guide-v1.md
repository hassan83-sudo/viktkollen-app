# Coach Memory User Guide V1

## Vad Coachen Kommer Ihåg

Coachminnet hjälper Viktkollen att anpassa råd efter säkra mönster och dina uttryckliga preferenser. Det kan till exempel komma ihåg vald coachton, föredragen actionstorlek och vilka fokusområden du vill prioritera.

## Granska Och Ändra

Öppna Adaptive Coach och välj `Granska coachminne`.

Där kan du:

- ändra coachton
- ändra actionstorlek
- välja fokusområden
- exkludera fokusområden
- glömma en härledd post
- glömma alla härledda poster
- slå på eller av personlig anpassning
- slå på eller av remote memory context

## Remote AI

Remote AI får inte använda coachminnet automatiskt. Det kräver aktivt samtycke och knapptryck. Regelbaserad coach fungerar även utan remote memory.
