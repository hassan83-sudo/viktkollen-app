# i18n rules

Ingen ny anvandarsynlig text far hardkodas i komponenter.

Nya features ska:
1. valja namespace
2. lagga svenska source keys
3. lagga engelsk referens
4. anvanda `t()`
5. darefter lagga andra locales

## Arkitektur

- `src/i18n/index.js` innehaller central i18n-konfiguration, browser detection och `lang`/`dir`.
- `src/i18n/languages.js` ar centralt sprakregistry med `code`, `name`, `nativeName` och `direction`.
- `src/i18n/resources.js` innehaller namespace-baserade locale-resurser.
- `npm run i18n:check` verifierar att svenska kallspraket och ovriga locales har samma namespace- och key-struktur.

## Nytt sprak

1. Lagga in sprakmetadata i `src/i18n/languages.js`.
2. Lagga locale-resurser i `src/i18n/resources.js`.
3. Kontrollera `normalizeLanguageCode()` for regional mapping.
4. Kor `npm run i18n:check`.
5. Testa `document.documentElement.lang` och `dir` om spraket ar RTL.
