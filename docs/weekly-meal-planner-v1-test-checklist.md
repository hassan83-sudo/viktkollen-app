# Weekly Meal Planner & Shopping List V1

## Manuell testchecklista

- Öppna Måltidscenter.
- Öppna Planera.
- Kontrollera aktuell vecka.
- Gå till föregående vecka.
- Gå till nästa vecka.
- Gå tillbaka till denna vecka.
- Lägg till meal från template.
- Lägg till egen planned meal.
- Redigera planned meal.
- Flytta till annan dag.
- Ta bort planned meal.
- Kopiera dag till annan dag.
- Kopiera dag till vardagar.
- Kontrollera nya id:n.
- Kontrollera planerat protein.
- Kontrollera planerade kalorier.
- Kontrollera målstatus.
- Kontrollera planeringsinsikter.
- Kontrollera planeringsförslag.
- Ändra dietary preferences.
- Kontrollera att inkompatibla mallar inte föreslås automatiskt.
- Registrera planned meal som faktisk meal.
- Kontrollera meal history.
- Kontrollera att planen finns kvar.
- Generera inköpslista.
- Markera varor.
- Lägg till manuell vara.
- Ändra kategori manuellt där UI:t tillåter det.
- Uppdatera från plan.
- Kontrollera att manuella varor finns kvar.
- Rensa markerade.
- Kopiera inköpslista.
- Fråga AI Coach om planen.
- Fråga AI Coach om inköpslistan.
- Kontrollera att planerad data inte syns som faktiskt intag.
- Rensa veckoplan.
- Kontrollera att meals och templates finns kvar.
- Kontrollera mobilvy.
- Ladda om sidan.
- Kontrollera att plan och lista finns kvar lokalt.

## Begränsningar

- Meal plans och shopping lists sparas lokalt.
- De ingår inte i Cloud Backup om nycklarna inte redan finns i befintlig allowlist.
- Planerade måltider är uppskattningar och räknas inte som registrerat intag.
- Inköpslistan tolkar bara enkla ingrediensrader deterministiskt.
